# Code of Conduct

We are committed to a welcoming, harassment-free experience for everyone.

## Expected behavior
- Be respectful and constructive.
- Accept feedback gracefully and give it kindly.
- Focus on what is best for the project and the community.

## Unacceptable behavior
- Harassment, discrimination, insults, or personal attacks.
- Publishing others' private information.
- Any conduct that would reasonably be considered inappropriate in a professional setting.

## Enforcement
Maintainers may remove, edit, or reject contributions and ban contributors who violate this code.
Report violations privately to the maintainers via a [GitHub private security advisory](../../security/advisories/new) or by contacting an organization owner.

This Code of Conduct is adapted from the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
