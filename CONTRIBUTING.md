# Contributing

Thanks for your interest in contributing!

1. Open an issue to discuss larger changes before starting.
2. Fork the repository and create a branch from the default branch.
3. Keep changes focused; add or update tests and docs where relevant.
4. Use [Conventional Commits](https://www.conventionalcommits.org) for commit messages.
5. Open a pull request describing what changed and why, linking the related issue.

By contributing you agree to follow our [Code of Conduct](CODE_OF_CONDUCT.md).
